# 파라오 코드 (수업용 웹 게임)

- 학생 화면: `index.html` — 접속 비밀번호 **0000**, 반·번호 입력 → 메뉴에서 선택
  - **개인 플레이**: 혼자 하는 연습 모드 (10라운드 × 60초, 점수는 그 기기에만 저장)
  - **학급 플레이**: 교사가 굴린 주사위로 반 전체가 동시에 겨루기
- 교사(방장) 화면: `admin.html` — 교사 코드 **0000**
  - 새 게임 열기 → 주사위 굴리기(누를 때마다 새 라운드) → 라운드 종료 / 게임 끝내기
  - 라운드 제한 시간, 타일당 최대 인원(기본 5명) 설정
  - 실시간 점수판 + 타일 현황(타일별로 몇 명이 가져갔는지)
- 주사위 3개(6·8·12면)를 **반드시 모두** 사용해야 타일을 가져갈 수 있어요.
- 비밀번호와 기본값은 `config.js`에서 바꿀 수 있어요.
